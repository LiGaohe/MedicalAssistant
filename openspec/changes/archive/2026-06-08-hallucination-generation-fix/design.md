## 修复方案

### 根因分析

幻觉产生于草稿生成和结构化阶段的LLM调用。通过benchmark数据分析，高频幻觉模式为：

1. **推断性幻觉**：对话中患者未说"曾去医院检查"，但LLM推断患者去过
2. **否定翻转幻觉**：对话中医生问"有没有咽喉炎"，患者未回答，但LLM编造"暂无咽喉炎"
3. **诊断过度幻觉**：对话中医生仅说"考虑上呼吸道感染"，但LLM写为确诊
4. **药物细节幻觉**：对话中未提及具体药物规格，但LLM编造"抗病毒药物（50mg规格）"

### 修复策略：强化提示词反幻觉约束

仅修改 `backend/services/llm/prompts/soap_generation.py` 中的3个提示词模板。

#### 1. `direct_soap_generation` 提示词

当前问题：缺少任何反幻觉约束。

修改：在字段说明后增加反幻觉约束段落：

```
## 严格约束
1. 只记录对话中明确提及的信息，不得推断、推测或添加
2. 否定性陈述（如"无XX"、"否认XX"）必须在对话中有明确依据，不得自行编造
3. 药物名称、剂量、规格必须在对话中有明确提及，不得编造具体数值
4. 诊断必须在对话中有医生明确表述，不得自行推断诊断结论
5. 如果对话中某信息不确定或未提及，对应字段留空，不要猜测
```

#### 2. `free_soap_generation` 提示词

当前问题：有"不得添加、推断或改写"约束，但缺少对否定性陈述和药物细节的约束。

修改：在撰写要求后追加约束：

```
6. 否定性陈述（如"无咽喉炎"、"否认XX"）必须在对话中有患者明确否认或医生明确排除的原文依据，不得自行编造否定结论
7. 药物名称、剂量、规格必须在对话中有明确提及，不得编造具体数值或规格
8. 诊断结论必须在对话中有医生明确表述，不得自行推断或升级诊断确定性
```

#### 3. `soap_structuring` 提示词

当前问题：有"不得添加草稿中未出现的内容"约束，但缺少否定翻转检测约束。

修改：在结构化原则后追加：

```
4. 否定性内容（如"暂无XX"、"否认XX"）必须在草稿文本中有明确出现，不得从对话中的疑问句推断否定结论
5. 药物、检查的具体数值和规格必须与草稿文本一致，不得添加或编造
```

### 不修改的部分

- `consistency_check_section` 提示词：幻觉检查逻辑正确，不需要修改
- `field_revision_patch` 提示词：字段修订逻辑正确，不需要修改
- 代码逻辑：不需要修改任何Python代码，仅修改提示词模板文本
