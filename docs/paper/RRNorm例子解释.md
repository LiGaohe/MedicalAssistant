以论文中多次提到的典型例子“**左膝退变伴游离体**”为例，完整展示RRNorm术语成分识别与重构思想的具体工作流程。

**1. 输入与目标**
*   **原始提及**：`左膝退变伴游离体`
*   **任务目标**：将其映射到正确的ICD-10标准术语。人工判断，它应对应两个标准术语：`膝关节病` 和 `膝关节游离体`。

**2. 术语成分识别（LLM驱动）**
这是核心思想的第一步。系统会构造特定的提示（Prompt），调用大语言模型对原始提及进行结构化解析。

*   **解析结果**：LLM将输入文本识别为一系列**成分**，并为每个成分打上**类型标签**（参见论文表2）。
    *   `左膝` -> **疾病范围** (DS: 发病的解剖部位)
    *   `退变` -> **疾病内容** (DC: 症状、病变)
    *   `伴` -> **分隔符** (SEP: 连接词)
    *   `游离体` -> **疾病内容** (DC: 症状、病变)

*   **结构化输出**：此时，原始的非结构化文本被转化为一个有序的成分序列：`[(DS: 左膝), (DC: 退变), (SEP: 伴), (DC: 游离体)]`。这一步成功识别出了“膝”这个身体部位被两个疾病内容共享，以及“伴”这个表示并列关系的分隔符。

**3. 原子提及重构（基于规则）**
基于上一步的结构化信息，系统应用预设的规则（论文中Algorithm 1）进行重组。

*   **规则应用**：规则核心是，当遇到一个“疾病内容”时，将其与前面所有相关的“修饰词”和每个“疾病范围”进行组合，以生成候选的原子提及。
    1.  处理到第一个DC `退变`：
        *   它前面的DS是 `左膝`。
        *   组合生成原子提及1：`左膝退变`。
    2.  遇到分隔符 `伴`，算法会调整搜索的起始位置。
    3.  处理到第二个DC `游离体`：
        *   根据规则和成分顺序，它依然与前面的DS `左膝` 关联（解决了“膝”的省略问题）。
        *   组合生成原子提及2：`左膝游离体`。

*   **输出**：原始的单一复杂提及，被分解为两个语义明确的**原子提及**：`{左膝退变， 左膝游离体}`。

**4. 赋能下游标准化任务**
分解完成后，后续的“召回-排序”框架将处理这些原子提及，而非原始提及：
*   **召回阶段**：模型会**分别**为`左膝退变`和`左膝游离体`从庞大的ICD-10术语库中检索最相似的候选术语。这比直接用`左膝退变伴游离体`去检索要准确得多。
*   **排序/选择阶段**：在最终从候选列表中确定标准术语时，系统不仅考虑原子提及与候选术语的整体相似度，还会利用**识别出的成分信息作为知识进行引导**。例如，模型会更关注“膝”（DS）和“退变”（DC）是否匹配，从而更准确地将`左膝退变`匹配到`膝关节病`，将`左膝游离体`匹配到`膝关节游离体`。

**总结示例**
通过这个例子可以看到，RRNorm的术语成分识别思想，**本质上是引入了一个基于LLM的“语义解析器”**。它将一个模糊的、复合的临床表述，翻译成了结构化的、机器可精确处理的“中间表示”（成分序列），再通过规则转化为多个标准任务可处理的“原子查询”。这种方法巧妙地解决了因缩写、并列和省略导致的语义模糊问题，是整个框架性能提升的关键。
