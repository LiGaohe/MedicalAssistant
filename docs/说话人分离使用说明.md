# funASR 说话人分离功能使用说明

## 功能概述

项目已集成 funASR 的说话人分离功能，使用 `cam++` 模型实现自动识别和区分不同说话人。

## 核心组件

### 1. FunASREngine

**位置**: `src/asr/funasr_engine.py`

**关键参数**:

- `spk_model`: 说话人分离模型，默认为 `"cam++"`
- `enable_diarization`: 是否启用说话人分离，默认为 `True`

**使用示例**:

```python
from src.asr import FunASREngine

# 创建启用说话人分离的引擎
engine = FunASREngine(
    device="cpu",
    model_id="paraformer-zh",
    vad_model="fsmn-vad",
    punc_model="ct-punc",
    spk_model="cam++"  # 启用说话人分离
)

# 或使用工厂方法
engine = FunASREngine.create_medical_version(
    enable_diarization=True
)

# 加载模型
engine.load_model()

# 转写音频
result = engine.transcribe("audio.wav")

# 获取说话人分离结果
for segment in result.speaker_segments:
    print(f"说话人: {segment['speaker']}")
    print(f"文本: {segment['text']}")
    print(f"时间: {segment['start_ms']}ms - {segment['end_ms']}ms")
```

### 2. ASRService

**位置**: `backend/services/asr_service.py`

**配置参数**:

```python
config = {
    "device": "cpu",
    "hotword_path": "config/hotwords_medical.txt",
    "enable_diarization": True  # 启用说话人分离
}

service = ASRService(config)
service.initialize()

# 获取带说话人分离的转写结果
result = service.transcribe_with_diarization("audio.wav")
```

### 3. 配置文件

**位置**: `backend/config.py`

**配置项**:

```python
class Settings(BaseSettings):
    ENABLE_DIARIZATION: bool = True  # 启用说话人分离
    ASR_DEVICE: str = "cpu"          # 推理设备
    HOTWORD_PATH: str = "config/hotwords_medical.txt"
```

## 输出格式

### ASRResult 数据结构

```python
@dataclass
class ASRResult:
    text: str                          # 完整转写文本
    language: str                      # 语言
    duration_seconds: float            # 音频时长
    inference_time: float              # 推理时间
    model_name: str                    # 模型名称
    segments: list                     # 转写片段
    speaker_segments: list             # 说话人分离片段
```

### speaker_segments 格式

```python
{
    "speaker": "spk0",           # 说话人ID
    "text": "你好，请问哪里不舒服？",
    "start_ms": 0,               # 开始时间（毫秒）
    "end_ms": 2500,              # 结束时间（毫秒）
    "confidence": 0.95           # 置信度
}
```

### 说话人映射

系统会自动将说话人ID映射为医生/患者：

- `spk0` → `doctor`（医生）
- `spk1` → `patient`（患者）
- `spk2+` → `speaker_2`（其他说话人）

## 性能优化建议

### 1. 设备选择

```python
# CPU 推理（适合开发测试）
engine = FunASREngine(device="cpu")

# GPU 推理（适合生产环境）
engine = FunASREngine(device="cuda:0")
```

### 2. 内存优化

对于长音频，建议调整 VAD 参数：

```python
engine = FunASREngine(
    vad_model="fsmn-vad",
    vad_kwargs={"max_single_segment_time": 6000}  # 最大单段6秒
)
```

### 3. 批处理优化

```python
result = engine.transcribe(
    audio_path,
    batch_size_s=300,           # 批处理总时长（秒）
    batch_size_threshold_s=60   # 长片段阈值
)
```

## 常见问题

### 1. 说话人分离不准确

**原因**: 音频质量差、说话人声音相似、背景噪声大

**解决方案**:

- 提高音频采样率（建议 16kHz 以上）
- 使用降噪预处理
- 调整 VAD 参数减少误分割

### 2. 内存不足

**原因**: 长音频处理时显存/内存占用大

**解决方案**:

- 减小 `batch_size_s`
- 减小 `max_single_segment_time`
- 使用 CPU 推理

### 3. 推理速度慢

**原因**: CPU 推理速度有限

**解决方案**:

- 使用 GPU 推理
- 减小模型规模（如使用 `paraformer-zh-streaming`）
- 优化音频预处理

## 模型说明

### cam++ 模型

- **类型**: 说话人验证/分离模型
- **参数量**: 7.2M
- **特点**: 轻量级、高准确率、支持重叠说话人

### 支持的说话人分离模型

- `cam++`: 推荐使用，平衡性能和速度
- `eres2net`: 更高准确率，但速度较慢
- `rdino`: 最新模型，性能最优
