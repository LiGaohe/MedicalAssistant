## 题目

基于医学术语纠错与检索约束的中文门诊 AI 问诊助手研究

## 研究背景

门诊问诊场景中，医生需要在有限时间内同时完成问诊、判断和病历书写。录音自动转写与结构化病历生成有望显著降低文书负担，但真正落地的难点并不在于把对话“写出来”，而在于把口语、噪声和非标准表达稳定地转成可用的医学术语。现有研究已经证明，从医患对话生成临床记录是可行的 \[1], \[2]，但医疗场景对事实一致性、关键遗漏和术语准确性要求远高于通用摘要任务。尤其在中文门诊场景中，患者常用口语描述症状，医生口述中又包含大量低频专科词、药名和检查名，这使得自动语音识别与大模型生成都容易出现术语错误和幻觉。

中文医疗对话信息抽取和结构化病历生成已有较好基础。MIE 将医患多轮对话中的症状、检查、手术及其状态抽取出来，证明“对话到病历”可以作为独立模块来建模 \[3]。SAFE 进一步表明，说话人身份和跨轮次交互对抽取准确率至关重要 \[4]。更近期的 EMRModel 说明，大模型配合微调与格式约束，已经能够把中文医疗咨询对话转成结构化病历 \[5]。但这些工作大多把重点放在抽取与生成本身，对术语纠错和事实约束的讨论仍不够充分。

因此，本课题拟围绕“医学术语纠错与降幻觉”这一核心问题，设计一个面向中文通用门诊录音的 AI 问诊助手。系统从录音出发，经过医疗 ASR、术语纠错与标准化、结构化病历生成三个环节，最终输出标准化病历，并给出术语校验依据。研究重点不在于单纯追求生成流畅，而在于提高医学术语的正确率、标准化程度和病历内容的事实可靠性。

## 国内外研究现状

### 端到端病历生成

国际上，医疗自动记录系统的研究已形成较清晰的路线。SOAP note 生成工作表明，按章节拆分的模块化摘要比纯抽象式生成更稳健，在长对话和 ASR 噪声下优势更明显 \[1]。MTS-Dialog 和 MEDIQA-Chat 等数据集推动了临床记录生成的系统评测，也让“关键遗漏”和“事实一致性”成为核心评价维度 \[2]。这些研究说明，病历生成不是普通摘要，而是强结构、强事实约束的临床文本生成任务。

中文场景中，MIE、SAFE 等工作主要聚焦于医疗对话信息抽取 \[3], \[4]。这一路线适合工程系统，因为它先抽取病历中的证据，再组织为结构化输出，可解释性较强。EMRModel 则展示了另一条路线，即将对话直接映射到结构化病历模板。该模型使用 LoRA 微调和代码风格提示，说明“格式约束的大模型生成”在中文结构化病历任务上已有较强可行性 \[5]。

### 医疗 ASR 与术语纠错

医疗录音中的低频术语识别是系统成败的前置条件。ASR-EC Benchmark 证明，仅靠提示词让大模型做中文 ASR 纠错效果有限，容易出现过度纠正。

在专科词识别方面，post decoder biasing 通过加权词表增强稀有医学词识别，对低频词的错误率有明显改善 \[7]。面向中文实体纠错的 DiCODER 则说明，词典检索、拼音相似性和受控解码可以减少低频实体误改和幻觉实体生成 \[8]。这类工作提示，医学术语纠错不应只依赖生成模型自发“猜测”，而应让词典、发音相似性和候选约束显式进入解码过程。

### 医学术语标准化与降幻觉

医学术语纠错的目的不应只是把错字改对，而应把转写结果映射为标准术语。MCSCSet 证明医学领域拼写纠错与开放领域差异很大，通用中文纠错模型迁移到医学场景会显著退化，因此必须依赖领域数据和领域混淆集 \[9]。在标准化层面，中文诊断和操作术语映射到 ICD 的研究表明，同义词知识库能显著提升规范化效果 \[10]。RRNorm 进一步指出，中文诊断表述中常有缩写、并列和多义压缩，必须先把复杂表述拆成更原子的术语成分，再做召回与排序 \[11]。这与门诊口语高度一致，因为患者口语和医生缩略表达本身就常是非标准的。

在降幻觉方面，Re3Writer 提出的 retrieve reason refine 框架说明，检索相似病例和引入医学知识约束，可以提升临床文本生成的忠实度与完整性 \[12]。MEDEC 则把医疗错误检测与纠错单独建成基准，说明“先发现错误，再纠正错误”的评测方式更能揭示系统是否真正具备临床可靠性 \[13]。这些工作共同表明，医疗文本生成要从“能写”走向“可信”，必须把检索、标准词表和错误检测纳入系统设计。

### 现有研究的不足

现有工作虽覆盖了病历生成、信息抽取、ASR 纠错、术语标准化和事实评测等多个环节，但仍存在三点不足：

- 中文门诊录音到标准病历的完整系统研究相对分散，模块之间常分别优化，缺少围绕术语准确性的统一设计
- 许多病历生成研究重点在文本相似度和整体摘要质量，对专科术语误识别和非标准表达规范化关注不足
- 降幻觉研究多面向英文临床文本生成，直接针对中文门诊口语与录音转写误差的证据约束机制仍不充分

因此，本课题具有明确的工程价值与研究空间。

## 研究目标与核心问题

本课题拟构建一个面向中文通用门诊问诊录音的 AI 问诊助手，完成以下目标：

- 将医患录音自动转写为带说话人信息的对话文本
- 从对话中抽取主诉、现病史、既往史、检查建议、用药信息等病历要素
- 将口语化和误转写的医学表达纠正并规范化为标准医学术语
- 生成结构化病历，并对关键术语给出检索校验与证据约束

围绕上述目标，课题聚焦以下核心问题：

1. 如何在门诊录音噪声、多说话人交互和低频医学词条件下，提高关键术语的识别率
2. 如何将 ASR 输出中的错词、同音词和非标准口语表达映射到标准医学术语
3. 如何在结构化病历生成过程中抑制幻觉，并减少关键医疗事实遗漏
4. 如何设计既适合工程实现又能反映临床可用性的实验方案与评价指标

## 研究内容与技术路线

### 总体思路

系统采用三阶段流水线，并在第二阶段与第三阶段之间加入术语校验闭环。

| 模块       | 输入         | 输出          | 关键方法                 |
| :------- | :--------- | :---------- | :------------------- |
| 医疗 ASR   | 门诊录音       | 带说话人标签的转写文本 | 医疗加权词表、置信度、n best 候选 |
| 术语纠错与标准化 | ASR 文本与候选词 | 标准化医学术语序列   | 词典检索、拼音匹配、候选约束、实体链接  |
| 结构化病历生成  | 纠错后对话与病历模板 | 结构化病历       | 大模型抽取生成、章节约束、检索校验    |
| 错误检测与回写  | 初版病历与证据库   | 修正后病历与证据说明  | 错误检测、候选比对、事实校验       |

### 模块一 医疗 ASR 与关键术语保留

ASR 模块以医疗词识别优先，而非单纯追求整体字错误率最低。参考 \[7]，系统将构建门诊医学词表，把疾病、症状、检查、药物和手术名称作为候选。该模块重点输出三类信息：

- 一次转写结果
- 关键片段的 n best 候选
- 词级置信度与说话人标签

这样的输出可以为后续术语纠错提供证据基础，而不把 ASR 结果视为不可更改的最终文本。

### 模块二 医学术语纠错与标准化

这是本课题的主创新模块。整体采用检测、可疑术语召回、受控纠错、标准化映射的四步流程。思路如下:

首先，识别可能出错的术语片段。通用纠错模型缺少医学知识，难以区分医学术语中的同音近音错误，因此需要构建专门的医学混淆集和领域模型 \[9]。其次，从医学词典中召回相似术语作为候选，综合考虑拼音、语义等信息 \[8]。再次，在纠错时只允许模型在候选集中选择，降低凭空生成新术语的风险 \[8]。最后，将纠错后的术语映射到标准词表。映射层可借鉴 recall rank 的实体链接框架，先召回候选、再排序选择 \[10]，并把复杂并列表达拆成原子术语后再规范化 \[11]。

### 模块三 结构化病历生成与检索约束

结构化病历生成不直接从原始 ASR 文本端到端生成，而是在纠错后的术语序列和病历模板约束下进行。信息抽取层可借鉴 MIE 和 SAFE，将病历要素视为实体加状态抽取任务，从对话中识别症状、检查、治疗建议及其肯定、否定、建议等状态 \[3], \[4]。生成层用代码风格模板或 JSON 模板约束输出字段，保证格式正确 \[5]。

为降低幻觉，病历生成后增加检索校验。系统从原始对话、术语词库和标准病历模板中检索支撑证据，要求关键字段能够在输入对话或知识库中找到对应依据 \[12]。若生成的疾病名、药名或检查名无法被检索支持，则触发错误检测与回写修正。

## 拟解决的关键技术问题

| 问题           | 形成原因                | 拟采用方法                             |
| :----------- | :------------------ | :-------------------------------- |
| 低频医学词识别错误    | 通用 ASR 词频不足，门诊语音噪声大 | 医疗词表，多候选保留 \[6], \[7]             |
| 同音错词与口语化误写   | 中文医学术语同音近音多，患者表达非标准 | 拼音相似召回，医学混淆集，受控纠错 \[8], \[9]      |
| 复杂诊断短语难规范化   | 缩写、并列、复合表达压缩多个含义    | 成分拆解为简单术语再重构 \[10], \[11]         |
| 结构化病历幻觉      | 生成模型脱离证据自由发挥        | 模板约束，检索增强，错误检测后回写 \[12], \[13]    |
| 评价结果与临床可用性脱节 | 只看 ROUGE 难反映风险      | 引入事实正确率、遗漏率、幻觉率和人工审核 \[15], \[16] |

## 创新点

### 创新点一

围绕“术语纠错与降幻觉”构建系统主线，而不是把它作为附属后处理。与仅关注病历生成质量的方案相比，本课题把术语准确性设为中心目标。

### 创新点二

提出面向中文门诊录音的受限候选医学术语纠错机制。该机制联合使用拼音相似和医学词典，避免大模型自由改写导致的过度纠正与幻觉实体。

### 创新点三

将术语纠错与术语标准化集成到同一流程中。系统不仅修正错词，还将非标准表达映射为标准病历术语或标准编码，提升输出的临床规范性 \[10], \[11]。

### 创新点四

在结构化病历生成后加入检索校验和错误回写机制，使关键字段具备可追溯证据，从而减少无依据生成和关键事实遗漏的情况 \[12], \[13]。

## 实验设计

### 数据集与数据构建

本课题拟采用“公开数据集验证方法 可控构造中文实验集验证系统”的思路。

| 任务        | 数据来源                    | 用途             |
| :-------- | :---------------------- | :------------- |
| 中文 ASR 纠错 | ASR EC Benchmark \[6]   | 验证中文 ASR 后纠错能力 |
| 医学拼写纠错    | MCSCSet \[9]            | 验证医学术语字符级纠错能力  |
| 中文医疗对话抽取  | MIE 数据集 \[3], \[4]      | 验证病历要素抽取能力     |
| 中文结构化病历生成 | 可参考 EMRModel 的任务设定 \[5] | 构造对话到病历字段映射实验  |
| 医疗错误检测与纠错 | MEDEC \[13]             | 借鉴错误检测与纠正评测协议  |

若难以获得真实中文门诊录音，可先构建小规模原型数据集。方法是选取标准中文病历模板，邀请标注者依据病历内容逆向编写问诊对话，再通过语音合成或真人朗读得到录音，最后注入可控 ASR 错误\[2]。

### 对比基线

实验至少设置以下基线：

- 原始 ASR 加通用大模型直接病历生成
- ASR 加术语词典纠错后病历生成
- ASR 加本课题受控术语纠错与标准化后病历生成

### 评价指标

评价分为四层。

| 层次  | 指标                                                                   | 说明                               |
| :-- | :------------------------------------------------------------------- | :------------------------------- |
| 识别层 | CER、关键词召回率、低频词错误率                                                | 评估ASR转写的单个字/词识别错误                |
| 术语层 | 检测P/R/F1、纠错P/R/F1、Top-k标准化准确率                                       | 评估医学专业术语的错词发现与标准化映射              |
| 病历层 | 字段级F1、加权F1、章节完整率                                                  | 评估结构化病历各字段的生成完整度                  |
| 安全层 | 事实精确率、事实召回率、遗漏率、幻觉率                                             | 评估生成病历与原始问诊记录的事实一致性              |

其中，病历生成不能只看 ROUGE。已有研究表明，自动指标与人工判断的相关性并不稳定，简单编辑距离在某些场景甚至不弱于复杂神经指标 \[15]。因此，本课题拟采用“自动指标加人工审核”的组合。

### 人工评测方案

参考 \[15] 与 \[2]，人工评测重点关注以下维度。

- 术语是否正确
- 是否存在遗漏
- 是否出现凭空生成的诊断、药物或检查
- 病历字段是否完整

可采用三名具有医学背景的评审者，对同一批样本进行双盲评分，并记录错误类型。错误标签可分为术语错误、事实矛盾、关键遗漏、格式错误和冗余表达。

## 技术可行性分析

从已有研究看，本课题具备较强可行性。

首先，中文医疗对话抽取与结构化病历生成已经存在可复用方法基础 \[3], \[4], \[5]。其次，中文 ASR 纠错、医疗拼写纠错和术语标准化都有公开任务设定与基线 \[6], \[9], \[10]。再次，检索增强和错误检测的研究已为降幻觉提供成熟思路 \[12], \[13]。因此，本课题不需要从零发明所有模块，而是可以在成熟模块上做面向中文门诊场景的系统整合与重点创新。

工程上，本课题可优先使用通用中文大模型配合 LoRA 微调和模板约束，实现较低成本的原型系统 \[5]。术语纠错模块则可以先从词典检索加重排序做起，再逐步加入受控生成和回写校验，技术路线清晰，阶段性成果明确。

- 一个面向中文门诊问诊录音的 AI 问诊助手原型系统

| 第五阶段 | 第 4 月     | 整理结果，撰写论文与系统说明                  |

## 结论

本课题面向中文门诊问诊录音这一高需求场景，拟构建一个从录音转写到结构化病历生成的 AI 问诊助手。与已有系统工作相比，本课题将医学术语纠错与降幻觉作为主问题，把医疗 ASR、术语标准化、结构化病历生成和检索校验串联为一条证据驱动的技术链。已有文献已经为各模块提供了坚实基础 \[3], \[4], \[5], \[6], \[9], \[12], \[13]。在此基础上开展面向中文门诊场景的系统集成与重点优化，具有明确的研究意义、工程价值和实现可行性。
